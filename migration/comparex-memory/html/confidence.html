How a few results become a trust score

Every approach, on every kind of problem (one L2 signature), gets a confidence between 0 and 1. It goes up with verified passes, down with failures, and older results slowly count for less. Build a history below and watch it move.

The curve is the weight of one outcome by age. It halves every 180 days. Dots are your outcomes; hollow dots are excluded from scoring.

The arithmetic
Why start at 0.5? The formula begins with one imaginary pass and one imaginary fail. Without them a single lucky pass would show 100%. With them, one pass gives 0.67, two give 0.75, five give 0.86.

When does a fix become a playbook?

A playbook is a fix memory is willing to recommend as “proven”. Memory checks these rules from top to bottom, and the first one that applies decides the status. The bench above feeds them live.

  1. A blocker caveat exists→ retired (blocker)
  2. Confidence is below 0.4→ retired (low confidence)
  3. A different approach won the last 3 issues while this one was not used→ retired (superseded)
  4. At least 2 passes, from 2 different issues, and confidence at least 0.7→ active
  5. None of the above→ candidate
Humans can edit a playbook's steps (memctl playbook edit). Once a person has edited them, memory never overwrites the steps again.
