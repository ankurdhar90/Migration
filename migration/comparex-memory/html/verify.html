Guide 4 · Ground truth

Did the fix work? Only Comparex gets to say.

A handoff file can claim anything. So memory ignores claims and waits for the next compare run on the same tables. If the issue's exact fingerprint (its L1 signature) is gone, the fix passed.

A pass can still be taken back

If the exact same problem shows up again within 30 days of a pass, the fix did not really hold. Memory marks the old outcome reopened, sets that issue's status back to reopened, and scores it as a fail from then on.
