Guide 8 · Building it

How Amp builds it, one phase at a time

Amp, running inside the enterprise, does the real work by following one prompt per phase. You review the output of each phase before sending the next prompt. Nothing moves forward until the previous phase's tests pass.

Who does what

You

Pick, review, approve

Choose the version, paste each prompt into Amp, read what it produced, and approve ALIGNMENT.md before any code. At the end, add one line to the agents' instructions.

Amp

Build against the real code

Reads the real repo, reuses what already exists, writes the memory code and its tests, and reports. It proposes, but never makes, changes to existing code.

This kit

The map

The guide, the prompts and tested reference code. It was written without seeing your code, so Amp adapts it instead of copying it.
